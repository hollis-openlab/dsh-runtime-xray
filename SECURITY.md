# Security Policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository when it is available. Do not open a public issue or pull request containing credentials, prompt content, environment values, or exploit details.

If private reporting is unavailable, contact the repository maintainers through GitHub before disclosing sensitive details publicly.

## Scope

The plugin is designed to be read-only and local to the active DeepSeek Harness process. Reports about secret disclosure, unauthorized mutation, unsafe remote exposure, dependency compromise, or bypasses of the export redaction policy are especially important.
